# 運命のお笑い診断

**あなたを笑わせる、運命のお笑いが見つかる。**

休日の過ごし方や生活習慣、性格についての簡単な質問に答えるだけ。
まだ知らない芸人・落語家・番組・動画との出会いを提案する、完全静的な日本語Webアプリです。

- 公開URL: https://fonfon-ai.github.io/unmei-geinin-shindan/
- お笑いの知識は不要。全17問・約2分。登録不要。
- **回答はブラウザ内だけで処理し、サーバーへ送信も端末への保存もしません。**

---

## 特長

- **お笑いを知らなくても答えられる**：漫才/コントの好みや「好きな芸人」を直接聞かず、休日・食・掃除・待ち合わせ・返信傾向などの生活習慣と性格だけを尋ねます。
- **決定論的なロジック**：回答 → 潜在特性 → 笑いの嗜好 → 診断タイプ → 推薦、というパイプラインで、同じ回答なら必ず同じ主結果を返します。実行時にLLMや外部APIは一切使いません。
- **偏らないカタログ**：昭和〜令和の芸人290組、落語家52名、番組34本を、特定の世代・事務所に偏らないよう収録（芸人の約半数は吉本興業以外）。
- **初心者にやさしい導線**：大量の固有名詞を一度に見せず、「まずはこの公式動画から」「まずは○分だけ」を明示します。
- **安全なリンク**：掲載URLは公式サイト/公式YouTubeチャンネル/公式配信のみ。すべて https の許可ドメインをコードで検証しています。

## 仕組み（概要）

1. 17問（うち5問は任意）に1問ずつ回答。
2. 回答を12の潜在特性（内向/外向、計画/即興、刺激/安定 など）に写像。
3. 潜在特性を9つの「笑いの特徴軸」（意外性・安心感・毒・緊張と緩和・関係性・身体性・言葉・テンポ・世界観）へ変換。
4. 最も近い診断タイプ（全12種）を決定。
5. 候補カタログの各エントリはタグから同じ9軸のベクトルを持ち、コサイン類似度でランキング。
6. 本命・初心者向け・意外な推薦・別世代・落語 をバランスよく選び、多様性を担保。

詳細は [docs/diagnosis-method.md](docs/diagnosis-method.md) を参照してください。

## プライバシー

- 回答はサーバーへ送信されません。
- 回答は localStorage / Cookie / アクセス解析等にも保存・記録しません。
- 診断はすべてブラウザ内で完結します。
- 外部SNS（X・LINE等）への共有機能は設けていません。診断はすべてブラウザ内で完結し、回答や結果が外部へ送信されることはありません。

詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## 免責

本サービスは心理検査や医学的診断ではなく、エンターテインメント目的の推薦です。
結果は「必ず当たる」ものではありません。掲載情報は2026-07-21時点で公式情報をもとに確認したものですが、配信状況などは変わることがあります。
芸人・番組の名称、外部リンク先の権利は各権利者に帰属します。本プロジェクトは人物写真・番組画像・ロゴ等を一切複製していません。

## 開発

前提: Node.js 20 以上（推奨 22）。

```bash
npm install        # 依存関係のインストール
npm run dev        # 開発サーバ
npm run typecheck  # 型チェック
npm run lint       # ESLint
npm run test       # ユニットテスト(Vitest)
npm run build      # 本番ビルド (dist/)
npm run preview    # ビルド結果のプレビュー
npm run verify     # typecheck + lint + test + build を一括実行
```

### 技術構成

- React 19 + TypeScript + Vite 6（完全静的、DB・サーバ・外部APIなし）
- 依存は必要最小限。実行時の外部通信は「外部リンクを別タブで開く」ときのみ。
- 本番ビルドは source map を公開しません。
- GitHub Actions（最小権限）で `main` への push 時に自動ビルド・デプロイ。

### ディレクトリ構成

```
src/
  data/        質問・診断タイプ・カタログ(芸人/落語家/番組/チャンネル)
  engine/      採点・笑い嗜好の写像・推薦・URL検証
  components/  UI(ランディング/質問/診断中/結果/カード)
  styles/      デザイン(システムフォント中心・ライト/ダーク対応)
docs/          仕様・診断手法・カタログ方針・セキュリティ・検証・出典
```
